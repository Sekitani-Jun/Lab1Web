# Praktikum HTML Dasar

Repositori ini berisi file pembelajaran dasar HTML yang dibuat untuk mata kuliah Pemrograman Web. Proyek ini bertujuan sebagai praktikum untuk mengenal tag-tag dasar HTML dalam menyusun struktur dan konten sebuah halaman web.

## Struktur File

Proyek ini terdiri dari dua halaman web utama yang saling terhubung melalui menu navigasi:

*   **`index.html`**: Halaman utama yang memuat dasar-dasar HTML seperti penyisipan gambar, serta variasi format teks (seperti *bold*, *italic*, *strong*, *subscript*, dan *superscript*). Halaman ini juga memiliki tautan navigasi ke halaman 2 dan website eksternal[cite: 2].
*   **`halaman2.html`**: Halaman Profil Mahasiswa yang menampilkan data diri atas nama Sekitani Jun dari Program Studi Teknik Informatika. Halaman ini berfokus pada penggunaan elemen *list* atau daftar berurut (`<ol>`) dan tidak berurut (`<ul>`) untuk menjabarkan keahlian, target belajar, dan urutan belajar.

## Teknologi yang Digunakan

*   **HTML**: Digunakan sebagai bahasa *markup* utama untuk membangun kerangka halaman[cite: 2].

## Cara Menjalankan

Karena proyek ini hanya menggunakan HTML statis, Anda tidak perlu melakukan instalasi khusus:

1. Unduh (atau *clone*) repositori ini ke komputer Anda.
2. Buka folder proyek tersebut.
3. Klik dua kali pada file `index.html` atau `halaman2.html` untuk membukanya secara langsung melalui web *browser* pilihan Anda (seperti Google Chrome, Firefox, atau Edge)[cite: 1, 2]
